¿QUIÉN LOS ENTRENÓ?

¿Ya están entrenados? ¿Por quién?

Servicios con capacidades preentrenadas

AWS proporciona la capacidad

En servicios como Rekognition, Textract o Comprehend, AWS proporciona y administra modelos entrenados previamente para tareas específicas.

Para utilizarlos, normalmente no necesitamos reunir datos de entrenamiento ni ejecutar nuestro propio entrenamiento.

AWS desarrolla, entrena y administra modelos para que podamos utilizar sus capacidades mediante servicios de IA.
CÓMO SE ENTRENAN

Detrás de una capacidad de IA hay un proceso de aprendizaje

De forma general, los equipos que desarrollan estos sistemas realizan un proceso parecido al ciclo que estudiamos.

Ejemplos

Datos

Se preparan grandes conjuntos de imágenes, documentos, audio o texto, según la tarea.

Aprendizaje

Entrenamiento

Los modelos ajustan sus parámetros para reconocer patrones o generar resultados útiles.

Comprobación

Evaluación

Se prueba el desempeño con datos separados y se revisan errores y limitaciones.

Ejemplo: para reconocer objetos en fotografías se utilizan ejemplos visuales; para convertir audio en texto se necesitan señales de voz y sus correspondientes transcripciones.

Esto describe el proceso general; AWS no publica todos los detalles, conjuntos de datos y arquitecturas de cada modelo utilizado por cada servicio.
