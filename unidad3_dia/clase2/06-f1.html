F1 SCORE

Combina Precision y Recall mediante su media armónica: un valor bajo en cualquiera de las dos reduce el resultado.

ConceptoMáximaAltaMediaBaja
Precision20 %44,4 %75 %100 %
Recall100 %100 %75 %50 %
Accuracy20 %75 %90 %90 %
F1 Score33,3 %61,5 %75 %66,7 %
F1 = 2 × (Precision × Recall) / (Precision + Recall). No es un promedio común: penaliza un desequilibrio entre ambos valores.

Calculemos paso a paso

ConfiguraciónSustitución de datos y resultado
Máxima2 × (0,20 × 1) / (0,20 + 1) = 33,3 %
Alta2 × (4/9 × 1) / (4/9 + 1) = 61,5 %
Media2 × (0,75 × 0,75) / (0,75 + 0,75) = 75 %
Baja2 × (1 × 0,50) / (1 + 0,50) = 66,7 %

¿Qué nos dice F1?

Media (75 %) presenta el mayor F1 en este conjunto: Precision y Recall son ambos 75 %. Baja tiene Precision perfecta, pero solo detecta la mitad de los incendios: por eso su F1 baja a 66,7 %. Máxima detecta todos, pero casi todas sus alarmas son falsas: F1 = 33,3 %.

¿Debemos elegir Media para una alarma de incendio? No automáticamente. Alta tiene F1 menor, pero detecta todos los incendios. La decisión depende del costo de cada error.
