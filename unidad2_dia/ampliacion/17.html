Casos reales: ¿qué tecnología utiliza cada solución?

Cinco situaciones, cinco soluciones. Observa qué tipo de aprendizaje, técnica y algoritmo se utiliza, y hasta qué nivel llega cada solución.

01 · HospitalAI

Un sistema experto apoya decisiones médicas

Utiliza reglas clínicas y una base de conocimientos para sugerir posibles infecciones y tratamientos. No se entrena con ejemplos para aprender sus reglas.

Learning TypeNo aplica: sistema basado en reglas
AI/ML TechniqueRazonamiento mediante reglas
Algoritmo / sistemaMotor de inferencia de sistema experto
AI · fuera de ML y DL
02 · SupermercadoML

Descubrir segmentos de clientes

Con frecuencia, gasto y descuentos, el modelo aprende grupos de clientes similares sin que la empresa le entregue segmentos etiquetados.

Learning TypeUnsupervised Learning
AI/ML TechniqueClustering
AlgorithmK-Means
ML → también AI; fuera de DL
03 · BancoML

Detectar una transacción fraudulenta

El banco entrena con operaciones históricas etiquetadas «Fraude» o «Válido», y después predice la categoría de nuevas transacciones.

Learning TypeSupervised Learning
AI/ML TechniqueClassification
AlgorithmDecision Tree
ML → también AI; fuera de DL
04 · InmobiliariaML

Estimar el precio de una vivienda

Aprende a partir de áreas, habitaciones, antigüedad y precios reales históricos. Para una casa nueva entrega un precio estimado.

Learning TypeSupervised Learning
AI/ML TechniqueRegression
AlgorithmLinear Regression
ML → también AI; fuera de DL
05 · FábricaDL

Reconocer defectos en fotografías

La fábrica entrena una red neuronal profunda con 20.000 fotografías etiquetadas como «Correcto» o «Defectuoso». La red aprende representaciones visuales y analiza fotografías nuevas.

Learning TypeSupervised Learning
AI/ML TechniqueClassification
ModeloConvolutional Neural Network (CNN)
DL → también ML → también AI
