Supervised Learning (Aprendizaje supervisado)

El modelo aprende a partir de datos con etiquetas objetivo: conoce la respuesta correcta de los ejemplos utilizados para entrenarse.

Datos: transacciones del banco

Monto, horario, dispositivo y país.

Etiquetas

Fraude / Válido.

Durante el Training, el modelo aprende relaciones entre datos y etiquetas. Durante la Inference, predice la respuesta de una transacción nueva.

Las etiquetas también pueden ser números, como el precio real de una vivienda.
