Construyamos una respuesta token por token

Escoge una continuación en cada paso: verás cómo cambia la lista de candidatos y cómo se construye una oración que tenga sentido.

¿Qué simula este laboratorio? Un LLM genera la salida paso a paso. Las probabilidades son ejemplos didácticos, no cálculos de un modelo real. Aquí mostramos palabras o expresiones como unidades visuales; un token real no siempre equivale a una palabra.

¿Cuál será la siguiente continuación?

Para explicar en clase: la selección de una continuación cambia el contexto de la siguiente predicción. El LLM real puntúa tokens de su vocabulario y no tiene un árbol fijo de opciones como este simulador.
